# 현재 경기 시스템 전체 정리

기준: 2026-10-16 작업 폴더의 코드와 정적 데이터. 기존 graphify 그래프로 위치를 찾은 뒤 현재 원본 코드를 확인했다. 실행 중인 세이브의 특정 경기 분석이 아니라, 현재 구현된 경기 시스템의 구조와 계산 규칙을 정리한 문서다. 이번 작업은 코드 열람과 문서 작성이며 Unity 실행·컴파일·테스트는 수행하지 않았다.

## 1. 전체 흐름

편성 → 편성 검증 → 쇼 실행 → 이벤트 순서대로 경기/프로모 계산 → 경기 기록·중계 생성 → 쇼 평점·팬 반응·정산 산출 → 기록 재생과 결과 확인 → 결과 확정 반영 → 주간 팬 증감.

- `ShowPlanningService`: 참가자, 팀, 경기 시간, 기믹, 승패, 스팟, 스토리, 타이틀의 유효성 검증.
- `ShowExecutionService`: 쇼 전체 실행 책임자. 경기에는 `MatchEvaluator`, 프로모에는 `PromoEvaluator`를 호출한다.
- `MatchEvaluator`: 입력 선수 구성, 스팟 사전 평가, 엔진 실행, 최종 경기 평점, 컨디션·부상 결과 작성.
- `MatchSimulator` / `MatchPhysics`: 행동 단위 경기 시뮬레이션.
- `FanAudienceService`: 경기별·프로모별 팬 만족도, 쇼 만족도, 선수 호감·관심 변화, 흥행 수요, 주간 팬 증감.
- `ShowResultApplicationService`: 검증된 결과를 실제 세이브에 확정 반영.

실행 중에는 복사한 상태에 앞 이벤트의 컨디션·부상·스토리·그룹 변화를 반영한다. 같은 쇼에서 뒤에 출전하는 선수는 앞 경기의 소모와 부상을 이어받는다. 실제 세이브에 영구 반영하는 단계는 결과 확인 뒤 별도로 있다.

## 2. 편성에서 정하는 것

- 경기 종류, 기믹, 진영과 진영별 선수, 대표 태그팀.
- 이기는 진영, 직접 승리하는 선수, 직접 패배하는 선수, 승리 방식.
- 경기 시간, 초반 스타일, 우세 진영.
- 입장·초반·중반·후반·경기 후 스팟.
- 스토리 연결과 진행/종결, 챔피언십 연결.
- 필요 승수, 아이언맨, 탈락제, 토네이도 옵션.
- 각본상 부상의 대상·부위·심각도·기간·결장 여부.

쇼와 개별 이벤트 시간은 양의 5분 단위이며, 이벤트 시간 합계가 쇼 제한 시간과 정확히 같아야 한다. 같은 쇼에서 같은 챔피언십은 한 경기만 편성할 수 있다. 참가자 중복, 존재하지 않는 선수, 팀 인원 불일치, 불가능한 피니시·기믹·스팟은 검증 대상이다.

실제 부상 때문에 `MatchUnavailable`/`Unavailable` 상태이거나 각본상 부상으로 결장 중인 선수가 있으면 경기 평가 경로에서 취소 결과를 만든다. 실제 쇼 실행은 그 전에 편성 검증도 통과해야 한다.

## 3. 경기 종류와 기믹

현재 정적 데이터의 개인전은 2~6명, 태그전은 총 4~8명·2~4팀·팀당 2~4명이다. 태그전 각 팀의 인원은 같아야 하며, 총인원 제한도 동시에 적용한다. 기본 컨디션 소모 배율은 개인전 1.0, 태그전 0.8이다.

- 기본 경기: 기믹 소모 배율 1.0.
- 스틸 케이지: 1.2. 핀·서브미션과 케이지 탈출 허용, 실격·카운트아웃 금지.
- 래더: 1.3. 물건 회수로 승리, 핀·서브미션·실격·카운트아웃 금지.
- 테이블: 1.15. 테이블 파괴로 승리, 핀·서브미션·실격·카운트아웃 금지.
- 하드코어: 1.25. 핀·서브미션 허용, 실격·카운트아웃 금지.
- 아이언맨: 1.0. 제한 시간까지 진영별 획득 승수 비교.
- 토네이도 태그: 1.0. 태그 교대 없이 팀원이 동시에 활동.
- 탈락 경기: 1.0. 패배한 선수를 탈락 처리.
- 3판 2선승: 1.0. 필요 승수 2, 정확히 두 진영이어야 한다.

기본 실격·카운트아웃은 개인전 참가자 3명 이상 또는 태그전 3팀 이상이면 금지된다. 기믹의 명시적 허용/금지 설정이 기본값보다 우선한다. 로프 브레이크 기본값은 허용, 카운트아웃 기본 시간은 10초다. 아이언맨과 탈락제는 함께 쓸 수 없고 토네이도는 태그전만 가능하다.

## 4. 선수 입력값과 역할

- 브롤링·파워·테크니컬·하이플라잉: 스타일별 수행력, 행동·기술 선택, 기술 수행 확률.
- 셀링: 기본 수행력의 25%, 접수 확률, 부상 부위 보호와 셀링 일관성 평가.
- 링 사이콜로지: 경기 구성, 행동 선택과 준비 과정, 관찰 판단, 매니아 팬의 보조 평가.
- 링 임프로비제이션: 카운터·기회 대응, 스팟 대실패 복구 등.
- 스태미나: 장시간 경기 감점, 경기 중 소모량과 회복 속도.
- 스팟워크·특수경기 능력·코미디: 해당 스팟의 수행 평가. 모든 행동에 일괄 보너스로 들어가는 값은 아니다.
- 카리스마·액팅·페이스워크·힐워크: 도발·케이페이브 행동, 역할별 팬 평가, 기습 성향 등에 사용.
- 마이크워크·프로모 임프로비제이션·코미디 등: 프로모를 통해 쇼 평점과 팬 반응에 관여.
- 컨디션: 시작 피로도 = `100 - 컨디션`. 스팟·기술 결과의 수행 평가에도 사용.
- 실제 부상·각본상 부상: 기술 제한, 시작 부위 손상, 출전 가능 여부.
- 선수 위상: 초반 진영 격차와 주도권에 사용.
- 선수별 시그니처·피니셔 목록: 기술 선택, 목표 부위와 피니시 준비에 사용.
- 팬층별 호감도·관심도: 기대치와 흥행 수요의 입력.
- 공식 태그팀/스테이블 케미스트리: 평가용 진영 능력 보정.

선수 화면의 경기 종합 능력치와 실제 경기 평점의 계산식은 다르다. 종합 수치를 그대로 최종 평점으로 사용하지 않는다.

## 5. 매치엔진의 진행 방식

현재 생성 엔진 버전은 4, 기본 최대 이벤트 수는 2,000개다. 프레임마다 물리 충돌로 승패를 계산하는 구조가 아니라, 조건을 만족하는 행동을 선택하고 이벤트·상태·동작 프레임을 생성한다.

한 단계는 단계 전환 판단 → 이어지는 공방/예정 스팟/피니시 확인 → 행동자·상대·행동 선택 → 수행·접수·방어 판정 → 위치·손상·피로·부상 처리 → 관중 반응 → 전후 스냅샷과 기록 저장 순서다.

### 경기 단계

오프닝, 대등한 공방, 한쪽의 지배, 컴백, 주고받기, 절정, 피니시의 7단계다. 고정 순서가 아니라 경기 진행 비율, 주도권 차이, 피로도, 최근 공격·니어폴, 관중 열기·드라마·강도에 따라 전환한다.

일반적인 피니시 단계 전환은 경기 진행률 85% 전에는 억제한다. 단, 진행률 65% 이후 니어폴이나 짧은 우세 경기의 결정적 공격 등 예외가 있다. 절정은 진행률 55% 전에는 결정적 공격이나 니어폴이 없으면 억제한다. 단계 진입과 실제 승패 확정은 별도다.

### 오프닝

자동·탐색·격돌·압도·기습을 지원한다. 자동 선택에는 진영 간 위상 격차, 상대 간 가장 강한 적대 관계, 기습 성향을 사용한다. 위상 격차가 25 이상이면 높은 위상 진영이 초반 우세 진영 후보가 된다. 힐의 기습 성향은 힐워크/20, 그 외는 0.05다.

오프닝 최대 구간은 목표 시간/5를 6~120초로 제한한다. 체인 공방, 누적 시간, 주도권 격차, 큰 공격이나 피니셔 등으로 종료 여부를 판단한다.

### 행동 선택

행동자는 주도권·행동 준비도가 높을수록, 피로가 낮을수록 선택되기 쉽다. 다운 상태는 불리하며 최근 연속 행동은 억제하고 최근 피격은 반격 기회를 만든다. 상대는 합법 참가 여부, 피로·다운·주도권, 최근 맞붙은 기록으로 가중 선택한다.

타격, 강타, 그래플, 부위 공략, 서브미션, 커버, 회복, 위치 이동, 리프트, 뒤집기, 로프·코너 공격, 공중기, 회피·후퇴, 도발, 태그, 협공·방해, 링 밖 추격, 사물 설치·등반·피니시 등을 지원한다.

가능한 행동만 후보에 넣고 능력·단계·피로·손상·반복·피니셔 준비 상태·관중 상태로 점수를 조정한 뒤 가중 무작위로 선택한다. 연속 기술과 의도한 콤비네이션은 일반적인 반복 억제에서 예외를 둔다.

### 연속 공방과 공간

커버, 홀드, 카운터, 체인, 로프·코너 시퀀스, 기술 준비, 콤비네이션, 링 밖 공방, 탑로프 경합, 동시 다운, 컴백을 이전 행동과 연결한다. 같은 공방 ID와 원인 이벤트를 기록한다.

위치는 중앙·로프·코너·탑로프·에이프런·링 밖, 자세는 서기·바로 눕기·엎드리기·앉기·무릎 꿇기다. 좌표·높이·방향·잡기와 잡힌 대상도 저장한다. 실제 위치·자세·부상 조건이 기술 후보와 로프 브레이크를 제한한다.

일반 태그는 팀의 첫 선수만 합법 참가자로 시작하고 나머지는 에이프런에서 대기한다. 토네이도는 이 제한을 풀며 탈락 선수는 행동 후보에서 빠진다.

### 기술 수행과 손상

기술별 능력 가중치, 수행·접수 난도, 요구 상황, 대상 부위, 이동·동작 프로필을 사용한다. 일반 기술 카탈로그와 선수 지정 시그니처·피니셔가 함께 사용된다.

일반 공격 수행 확률은 `0.91 + (수행 능력 - 난도) × 0.012 - (피로 × 0.035 + 실제부상단계 × 0.5) × 0.015`를 0.15~1로 제한한다. 접수 확률은 `0.94 + (셀링 - 접수난도) × 0.004`를 0.5~0.99로 제한한다. 방어·카운터는 별도로 판정하며 준비된 각본 피니시 구간에는 다른 제약을 적용한다.

머리·몸통·팔·다리 손상, 스턴, 피로, 누적 활동량, 최근 충격과 시간이 유지된다. 일반 피격은 활동 소모에 충격×0.35, 부위 손상에 충격×0.45, 스턴에 충격×1.6을 사용한다. 충격 6 이상은 다운을 유발한다. 이벤트가 지날 때 스턴은 초당 0.35씩 감소한다.

행동 소모는 `작업량 × (1.25 - 스태미나 × 0.035)`다. 회복은 스태미나에 따라 빨라지지만 시작 피로와 누적 소모가 회복 하한을 만든다. 손상과 실제 부상은 단순 휴식으로 사라지지 않는다.

### 링 밖과 해설 테이블

2인 경기의 링 밖 공방 후보 확률은 힐 포함 시 45%, 아니면 18%다. 이는 경기 시작 시 자격을 뽑는 확률이며 실제 발생 보장은 아니다.

해설 테이블 후보는 2인 핀/서브미션 목적 경기, 중요 경기, 실격 금지, 카운트아웃 금지 또는 30초 이상, 목표 15분 이상을 모두 만족할 때 12%다. 중요 경기는 메인이벤트 또는 스토리 종결 경기다. 준비·공격 조건도 충족해야 실제 장면이 발생한다.

## 6. 승패와 각본

메인 게임은 편성한 승자·패자·피니시를 엔진에 전달한다. 엔진은 이를 실행할 수 있는 준비와 합법 조건을 만들며, 능력치만으로 최종 승자를 자유 추첨하는 구조가 아니다. 다만 예정 스팟, 실제 부상, 실행 불능은 결과를 바꿀 수 있다.

일반적인 각본 경기는 목표 시간의 ±5%를 종료 허용 범위로 사용한다. 아이언맨과 각본 무승부는 이 여유를 쓰지 않는다. 중등 부상 구조 절차는 별도 마감 시간을 확장할 수 있다.

- 핀: 상대 다운·자세, 링 안, 합법 참가자, 심판 가용성, 로프 브레이크 등을 검사하고 커버 준비와 카운트를 진행한다.
- 일반 핀 확률: `0.005 + 상대피로×0.002 + 상대스턴×0.005 + 최근충격×0.007 + 몸통손상×0.002`. 피니셔 직후 +0.20, 오프닝에서는 전체×0.08, 결과는 0.001~0.92로 제한한다. 최근 충격은 시간에 따라 감쇠한다.
- 일반 서브미션 홀드는 지속 중 부위 손상과 소모를 누적한다. 승리 가능성은 기본 0.03 + 대상 부위 손상×0.003이며 각본상 승리 허용 조건도 통과해야 한다. 탈출·로프 브레이크·실신 판정이 있다.
- 롤업, 실격, 카운트아웃, 무승부, 탈출, 물건 회수, 테이블 파괴를 지원한다.
- 아이언맨은 제한 시간 종료 시 진영별 합산 승수를 비교한다. 탈락제는 상대를 제거하고 남은 상대 여부로 종료한다.
- 종료 준비를 합법적으로 완료하지 못하면 실행 중단 무승부 기록을 만들 수 있다. 이 경우 실제 수행 평점은 따로 보존하지만 최종 경기 평점은 0, 비평가 평가는 없다.
- 이벤트 상한 도달 등 완결되지 않은 시뮬레이션은 쇼 평가 단계에서 예외로 거부한다.

## 7. 스팟과 난입

특수 스팟 카탈로그에는 입장 기습, 제3자 습격, 경기 무산·중단, 심판 오폭·유인, 발목 잡기, 흉기 전달, 태그 파트너 배신, 몰래 공격, 암전 습격, 난입 실격, 경기 후 공격·보복·악수 뒤 배신 등 16개가 있다. 일반 기술·공방 스팟 카탈로그도 별도로 있다.

스팟은 허용 경기·구간·주체가 참가자/외부인인지·상대/팀원 관계를 검증한다. 현재 입력에서는 별도 파트너 지정은 허용하지 않는다.

스팟 평가의 시전자 역할 점수는 `(스팟워크×2 + 해당 전문 능력)/3`, 접수자는 `(스팟워크×2 + 셀링)/3`이다. 여기에 `(100-컨디션)/20`과 실제 부상 감점 1/3/6을 뺀다. 시전자 역할 점수는 최종 수행 평균에 두 번 들어간다.

수행력과 난도 차이를 로지스틱 확률로 변환해 대실패·실패·성공·대성공을 뽑는다. 대실패는 참여자의 평균 링 임프로비제이션/20 확률로 실패까지 복구할 수 있다.

- 기본 점수 배율: 대성공 1.5, 성공 1, 실패 -0.5, 대실패 -1.5.
- 반복 집계: 해당 날짜 포함 최근 56일의 같은 스팟, 같은 쇼의 앞선 경기, 같은 경기의 앞선 동일 스팟.
- 성공 계열 반복 배율: `max(-0.5, 1.1 - 0.2×반복수)`. 반복 과다 시 성공해도 음수 점수가 될 수 있다.
- 실패 계열 반복 배율: `min(1.5, 1 + 0.1×반복수)`.
- 엔진 적용 시점: 입장 0%, 초반 20%, 중반 50%, 후반 80% 이후. 필요한 자세·상황을 기다릴 수 있으며 구간을 놓치거나 안전 조건이 안 맞으면 미실행, 점수 0이다.
- 심판 오폭/유인 스팟은 심판을 18초간 사용할 수 없게 한다.
- 경기 중단·실격의 각본 효과와 수행 점수는 별개다. 연출 실패가 배신 사건 자체의 취소를 의미하지 않는다.
- 경기 후 스팟은 중단·중상 등 조건을 검사해 적용 여부를 기록하며, 일반 경기 중 공격 이벤트와 같은 방식으로 전부 재시뮬레이션하지 않는다.

## 8. 부상과 컨디션

실제 부상과 각본상 부상을 구분한다. 중등 이상 실제 부상은 머리·다리·팔·몸통 위치에 따라 공중기·러닝·그래플·서브미션의 시전 또는 접수를 제한한다. 중상은 의료 중단 무승부를 만든다.

사고 판정은 실제 공격에만 적용하고 카운터 처리된 공격은 제외한다. 수행 실패·접촉 오류·고위험 기술이 사고 후보를 만든다. 수행 실패/접촉 오류가 있으면 기본 부상 확률 1%, 고위험 기술만 해당하면 0.01%이며 피해자 피로에 따라 `1+피로/100`을 곱한다. 이는 매 공격의 무조건 부상 확률이 아니다.

부상 발생 뒤 심각도 분포는 경상 80%, 중등 18%, 중상 2%다. 기본 회복 기간은 7/21/60일이다. 중등 부상은 각본 무승부가 아닌 경기에서 안전 피니시 구조 절차를 요구하며 현재 시각+90초의 마감 시간을 둔다.

각본 부상은 지정 부위에 심각도 단계×25의 시작 손상을 만든다. 새 각본 부상은 기간 1~365일을 검증하며 실제 경기 시간이 있고 실행·의료 중단이 아닌 경우 결과에 추가한다.

경기 후 컨디션 비용은 다음을 3~30으로 제한한 값이다.

`실제경기분×0.6×경기종류배율×기믹배율 + min(실제경기분×0.1, 엔진누적소모×0.02)`

여기서 비용에 사용하는 실제경기분은 엔진 초를 분으로 올림한 결과다. 평점의 시간·스태미나 계산은 엔진 초/60의 소수 분을 쓴다. 입장 스팟으로 경기 시간이 0이 된 경우도 평가가 끝까지 진행되면 최소 비용 3이 적용된다. 선수 부재로 취소 결과를 조기 반환한 경기는 이 비용 생성 단계에 도달하지 않는다.

## 9. 경기 평점

최종 경기 평점 범위는 0~20이다.

1. 스타일 수행력 = 브롤링·파워·하이플라잉·테크니컬의 스타일 가중합.
2. 개인 기본 수행력 = 스타일 수행력×0.75 + 셀링×0.25.
3. 개인 유효 수행력 = 기본 수행력 + 선수별 난수 편차 - 장시간 스태미나 감점, 0~20 제한.
4. 진영 수행력은 팀원 유효 수행력 평균에 케미스트리 보정을 더한다.
5. 구성력 = 진영 링 사이콜로지 평균×0.70 + 가장 높은 진영 링 사이콜로지×0.30.
6. 기초 평점 = 진영 수행력 평균×0.70 + 구성력×0.30.
7. 관찰 점수 = 실제 수행×0.35 + 구조×0.25 + 판단×0.25 + 셀링×0.15.
8. 엔진 반영 후 기초 평점 = 기초 평점×0.70 + 관찰 점수×0.30.
9. 최종 = `시간 배율을 적용한 기초 평점 + 미실행이 아닌 스팟 점수 합`, 0~20 제한.

관찰 수행은 실제 공격의 수행 품질, 판단은 유효한 커버와 상황에 맞는 기술 선택, 셀링은 손상 부위 보호와 모순 여부, 구조는 목표 부위 공략 뒤 준비·연결·피니셔 직전 45초 내 준비 행동을 평가한다. 2인 비태그 경기에서는 같은 상대에게 최근 공격 4개 중 같은 기술이 이미 두 번 이상 나온 반복을 구조 감점에 사용한다. 의도한 콤비네이션은 제외한다.

### 난수·체력·케미스트리

개인 편차는 두 균등 난수를 합친 삼각형 분포다. 기본 범위 ±0.50, `trait_012` ±0.25, `trait_013` ±1.00이며 둘 다 있으면 `trait_013`이 우선한다. 경기 전체에 또 다른 단일 난수 점수를 더하지는 않는다.

스태미나 수용 시간은 `2.5×스태미나-2.5`분을 5~50분으로 제한한다. 초과 시간이 0/5/10/15/20분일 때 감점 0/1/3/6/10을 선형 보간하며 20분 이상 초과해도 최대 10이다.

공식 2인 태그팀이면 저장된 케미스트리, 그 외 전원이 속한 활성 스테이블이면 그 케미스트리, 해당하지 않으면 30을 사용한다. 비태그는 기본 50이다. 보정은 `(케미스트리-50)/50`이며 평가용 진영 능력에 적용된다. 이 보정이 엔진 개인 능력치 전체를 바꾸는 것은 아니다.

### 경기 길이

15~28분은 길이 배율 1이다. 8분 이하 짧은 경기와 32분 이상 긴 경기에는 기초 평점에 따른 감쇄를 적용하고, 8~15분·28~32분은 부드럽게 보간한다.

- 짧은 경기 계수: 기초 평점 0/10/13/15/17/20에 1/1/0.95/0.90/0.85/0.75.
- 긴 경기 계수: 기초 평점 0/7/10/13/15/20에 0.65/0.65/0.75/0.85/0.95/1.

짧은 고품질 경기의 평점 상한을 억제하고, 낮은 품질의 긴 경기를 감점하는 구조다. 시간 배율은 스팟 점수에는 곱하지 않는다.

## 10. 경기 중 내부 수치

`CrowdHeat`, `Drama`, `Intensity`는 각각 0~100인 내부 수치다. 이 절의 열기·드라마·강도는 설명용 번역이며, 확인된 게임 화면의 공식 표기가 아니다. 경기 생성 시 별도 초기값을 넣지 않아 0에서 시작한다.

- 주요 장면: 피니시·폴·태그·방해, 니어폴, 충격 9 이상.
- 주요 장면 기본 반응 = `max(1, 7 - 최근12이벤트의 같은 행동자·행동 반복수)`.
- 일반 장면 반응 = 충격×0.2.
- 수행 실패·접수 실패는 반응 -2. 일부 컴백 장면은 페이스워크/힐워크 기반으로 개별 반응을 설정한다.
- 열기 = 기존 열기 + 이번 반응. 휴식 행동이면 추가 -2.
- 드라마 = 기존 드라마×0.995 + 주요 장면 반응, 일반 장면은 -0.15.
- 강도 = 기존 강도×0.8 + `min(20, 충격×1.1)`.

낮은 열기에서는 강타·시그니처·피니셔 선택을 늘리고, 드라마와 강도는 행동 선택과 단계 전환에 다시 영향을 준다. 이 피드백은 있다. 그러나 실제 입장 팬 수, 팬층 비율, 선수 호감·관심을 읽어 초반 열기나 매 장면 반응을 가중하는 구조는 현재 없다.

## 11. 경기 후 팬 반응

팬은 몰입형, 캐주얼, 매니아의 3층이다. 결과 데이터의 기존 필드명은 각각 Family/Light/Mania에 대응한다. 팬층마다 선수의 호감도와 관심도를 0~100으로 따로 저장한다. 단체 팬층에는 팬 수·만족도·주간 노출량이 있다.

### 기대치와 만족도

팬층별 이벤트 기대치 = `42 + 참가자 평균(관심도×0.28 + |호감도-50|×0.06) + 쇼 종류 보정`.

쇼 종류 보정은 일반 0, 일반 PPV +4, 메이저 PPV +6, 시그니처 PPV +8이다. 호감도가 50에서 멀면 긍정·부정 양쪽 모두 기대치가 오른다.

- 몰입형 제공 품질 = 경기 품질×0.70 + 역할 수행×0.30. 역할 수행은 힐이면 힐워크, 그 외 페이스워크의 참가자 평균×5.
- 캐주얼 제공 품질 = 경기 품질×0.80 + 카리스마 평균×5×0.20.
- 매니아 제공 품질 = 경기 품질×0.95 + 링 사이콜로지 평균×5×0.05.
- 여기서 경기 품질은 최종 평점×5, 프로모는 프로모 점수를 사용한다.
- 만족도 = `50 + (제공 품질 - 기대치)×1.2`, 0~100 제한.
- 쇼 팬 만족도는 이벤트 만족도를 예정 시간으로 가중 평균한다. 취소 이벤트도 예정 시간 비중에 포함되며 품질·역할 수행은 0으로 계산한다.

몰입형과 매니아의 평가 관점은 다르지만, 매니아가 특정 기믹을 선호하는 전용 보너스 같은 별도 항목은 이 공식에 없다.

### 선수 호감·관심 변화

각 이벤트의 노출 계수는 `min(1, 예정분/20)`이다.

- 일반 호감 변화 = `(만족도-50)×0.045×노출`.
- 몰입형층의 힐 호감 변화 = `-max(0, 만족도-40)×0.035×노출`. 좋은 힐 연기가 호감 하락으로 나타날 수 있다.
- 관심 변화 기본 = `0.7 + (만족도-50)×0.045`.
- 양의 관심 변화에는 `1-현재관심/100`, 음의 변화에는 `현재관심/100`을 곱하고 노출 계수도 적용한다.
- 쇼 안의 변화들을 합쳐 팬층별 호감·관심 각각 -3~+3으로 제한한 다음 출연 간격 보정을 곱한다.
- 지난 갱신과 같은 날 또는 이전 날짜면 0배, 1~6일이면 0.35배, 7일 이상이면 1배. 갱신 기록이 없으면 7일로 취급한다.
- 취소 이벤트에서는 선수 호감·관심 변화가 없다.

동일 경기의 참가자는 팬층별 만족도를 공유한다. 승자·패자에게 별도 승패 보너스를 주는 공식은 없다. 다만 힐 역할 및 각자의 기존 관심도 때문에 실제 변화량은 달라질 수 있다.

## 12. 단체 팬 유지·성장과 흥행

새 팬 데이터 초기값은 총 2,500명, 몰입형 35%·캐주얼 40%·매니아 25%다. 팬층별 최대 팬 수는 10억 명이다.

쇼 노출량은 `min(1, 예정총분/90)`. 단체 만족도는 `(쇼만족도-기존만족도)×0.4×반영노출`만큼 이동하며 주간 누적 노출 상한은 1.5다.

7일마다 아래를 팬층별 계산한다.

- 유입률 = `주간노출 × (0.003 + max(0, 만족도-50)×0.0006)`.
- 이탈률 = 노출 0이면 0.004, 아니면 `0.003 + max(0, 50-만족도)×0.0006`.
- 순증률 = 유입률-이탈률, -2%~+2% 제한.
- 팬 수에 순증률을 적용하며 소수 나머지를 다음 주로 이월한다.
- 만족도는 50 방향으로 10% 이동하고 주간 노출은 0으로 초기화한다.

기본 티켓 수요는 팬층별 팬 수·기대치·만족도를 사용한다. 여기에 비일반 쇼 1.2배, 가격 구매력, 쇼 길이(90분에 최대), 최근 7일 완료 쇼 수에 따른 `1/(1+0.35×최근쇼수)` 감쇄를 적용한다. 현재 시장은 지역 분할 없이 하나다.

기준 티켓가는 공연장 기본가×쇼 배율이다. 쇼 배율은 일반 1, 일반 PPV 1.5, 메이저 2, 시그니처 3이다. 플레이어 가격은 기준가의 60~160%, 가격 수요 계수는 `1 + (1-실제가/기준가)×0.75`다. 실제 관객은 가격 반영 수요에 95~105% 변동을 적용한 뒤 공연장 수용 인원으로 제한한다. 수입은 실제 티켓가×실관객, 순이익은 수입-쇼 예상 비용이다.

이번 경기 품질이 이미 팔린 이번 쇼 티켓 수를 사후 변경하지는 않는다. 이번 결과는 만족도·팬 수 변화 등을 통해 이후 수요에 영향을 준다.

## 13. 스토리·관계·타이틀·프로모

스토리는 관심도·긴장도·피로도, 선수 간 관계는 별도로 관리한다. 이전 사건의 관계는 다음 경기 오프닝 적대감에 사용된다. 경기·난입·배신·경기 후 공격은 스토리 변화와 새 스토리 후보를 만들 수 있다.

경기 품질은 스토리 관심 변화에 사용된다. 일반 사건의 관심 변화는 `(품질-50)/10 - 최근반복수×2`, 반복 피로는 반복수×3이다. 사건 반복은 최근 3개 사건에서 집계한다. 공격·배신·구출·화해 등은 각자의 긴장·관계 변화값을 갖는다. 현재 일반 경기 평점 계산에는 연결 스토리의 관심·긴장·피로를 직접 더하는 항목이 없다.

타이틀은 편성 적합성과 결과 확정 후 챔피언·재위 기록 처리에 연결된다. 타이틀전 자체에 경기 품질이나 팬 만족도 보너스를 직접 더하는 항목은 현재 공식에 없다.

프로모도 같은 쇼 타임라인에서 실행한다. 기본 점수는 주화자 60%+다른 참여자 평균 40%, 단독이면 본인 점수, 영상/광고형은 제작 수행을 사용한다. 실제 호출 경로의 개인 프로모 수행은 `WrestlerOverallCalculator.Promo×5`다.

프로모에는 스토리 맥락 보정이 실제 전달된다. 역할 적합·목적 적합·시간 적합·신선도·결과 편차 입력 필드는 있지만 현재 `ShowExecutionService`는 이 값들을 채우지 않아 기본 0이다. 필드 존재와 실제 적용을 구분해야 한다.

## 14. 쇼 평점·별점·재생

일반 쇼 평점은 경기 평점×5와 프로모 점수를 예정 시간으로 가중 평균한다. 취소 이벤트는 이 일반 쇼 평점의 분모·분자에서 빠진다. 이는 취소도 포함하는 팬 만족도 집계와 다르다.

경기 비평가 점수는 `경기평점×5 + (스토리점수-50)/10`. 현재 호출은 기본 스토리점수 50이어서 실제 추가 보정은 0이다. 따라서 보통 경기 비평가 점수는 최대 100이다.

쇼 비평가 점수는 경기 비평가 평균 55% + 상위 3경기 평균 20% + 흐름 15% + 스토리 10%다. 현재 호출은 흐름·스토리 각각 50을 사용하므로 두 항목은 합계 12.5점으로 고정된다. 평가 가능한 경기가 없으면 쇼 비평가 평가는 없다.

별점 변환 함수에는 100점=5성, 101=5.25, 102=5.5, 103=5.75, 104=6, 105=7의 경로가 있지만 현재 경기 호출에서 스토리 보정 없이 100점 초과는 나오지 않는다.

게임은 `ShowExecutionService.Execute`로 먼저 전체 결과를 저장한 뒤 `ShowSimulationPlayer`로 기록을 재생한다. 일시정지·1/2배속·다음 이벤트·끝내기는 이미 계산된 결과를 보는 조작이다. 중계는 엔진 이벤트를 읽어 생성하며 기술·접수 실패·니어폴·부상·원인 공방을 표현한다.

별도 `TopViewTest`에는 같은 엔진 기록을 공간·동작·충격 효과·해설 테이블과 관중 패널로 보여주는 재생기가 있다. 이쪽 관중 패널 점등 수는 관중 열기를 사용한다. 메인 쇼 재생 화면과 별도 테스트 장면을 하나의 화면으로 혼동하면 안 된다.

## 15. 결과 확정과 재현성

결과 확정 단계에서 컨디션, 실제·각본 부상, 출전일·경기일, 공식 경기 수, 팬 반응, 단체 만족도, 스토리·관계, 태그팀·스테이블, 챔피언십, 정산 거래를 반영하고 쇼·일정을 완료 처리한다. 처리 키로 중복 적용을 방지한다.

이벤트 난수는 쇼 결과 시드·쇼 버전·이벤트 ID에서 만든다. 선수 수행 편차는 선수 ID별 시드를 사용한다. 스팟·안전사고는 별도 난수 스트림이다. 같은 입력과 시드의 게임 계산 재현성을 의도한 구조이며, 생성 결과 ID까지 모두 동일하다는 뜻은 아니다.

현재 승패 뒤 모든 선수의 위상·모멘텀·능력치를 자동 증가/감소시키는 종합 성장 처리는 이 결과 반영 경로에서 확인되지 않는다. 관련 상태 데이터가 존재한다는 것만으로 경기 후 변화가 구현됐다고 볼 수 없다.

## 16. 실제 연결과 연결되지 않은 항목

- 실제 연결: 컨디션/부상 → 엔진 행동 → 관찰 평가 → 최종 평점 → 팬 만족도 → 호감·관심/단체 만족 → 주간 팬 수 → 이후 티켓 수요.
- 실제 연결: 관계 → 오프닝 적대감, 위상 격차 → 초반 주도권, 경기 스팟 → 스토리·관계, 이전 경기 소모 → 같은 쇼 뒤 경기.
- 현재 직접 연결 없음: 기존 팬층 구성·선수 인기 → 경기 중 열기 초기값, 경기 중 열기 최종값 → 팬 만족도 직접 입력.
- 현재 직접 연결 없음: 승자/패자 구분 → 팬 변화 보너스, 타이틀전 여부 → 최종 평점 가산.
- 현재 호출에서 미적용: 경기 비평가의 별도 스토리 점수, 쇼 비평가의 실제 흐름·스토리 점수, 프로모의 역할/목적/시간/신선도 보정.
- 열기는 행동과 단계 전환을 바꾸므로 최종 품질과 팬 만족도에 간접 영향은 줄 수 있다. 직접 입력이 없다는 것과 완전히 무관하다는 것은 다르다.
