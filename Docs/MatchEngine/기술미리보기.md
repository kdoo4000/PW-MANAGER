# 기술 미리보기

`Assets/TopViewTest/Move Preview.unity`를 열고 Play로 실행한다. 왼쪽에서 상황을 고르거나 한글·영문 이름을 검색하고 기술을 선택한다. 오른쪽에서 시전 예시를 확인한다. 재생 위치 슬라이더를 움직이면 일시정지하며, 다시 재생·반복 재생과 0.5/1/1.5배속을 지원한다.

현재 목록은 호환용 중복 3개를 제외한 175개다. 148개는 2인 미리보기를 지원한다. 아직 구현하지 않은 상황 25개와 3인 더블팀 2개는 선택 시 준비 중인 이유를 표시한다. 선수 이름 대신 시전자·접수자 역할만 표시하며 저장된 선수나 무브셋을 변경하지 않는다.

## 기술별 동작 데이터

`Assets/Game/Data/Resources/PWManagerRuntime/MatchMoveMotions.csv`에 148개 기술의 836개 동작 지점을 저장한다. 경기 엔진과 미리보기가 같은 테이블을 사용한다. 기존 `MatchMoves.csv`의 ID로 연결하며, 일반·시그니처·피니셔에서 같은 기술은 같은 동작을 사용한다.

`MatchMoves.csv`의 ExecutionStyle은 Stationary(제자리), Running(달리기), Aerial(공중)로 시전자의 움직임을 구분한다. 상대의 자세·링 위치를 나타내는 Situation과 별개다. 현재 미리보기는 제자리 타격 중 Strike/Kick 프로필의 기본 길이를 1.2초로, 달리기 타격은 2초로, 다른 기술은 3초로 사용한다. 제자리 타격의 Progress 0.5~0.65는 최대 1.8배로 재생한다. 달리기 타격은 재생 배율을 일정하게 유지하고 이동 경로에서 가속과 감속을 표현한다. 기술 ID나 시그니처·피니셔 지정은 바뀌지 않는다. 하나의 기술이 여러 시전 진입 방식을 선택하는 기능은 별도의 개선 항목이다.

동작 표의 ActorPosture/TargetPosture는 해당 시점의 자세를 지정한다. Start는 기존 기록의 자세를 사용하고, Standing/Supine/Prone/Seated/Kneeling을 지정할 수 있다. 자세와 Grounded, 종료 상태의 IsDowned를 함께 갱신한다. 서브미션의 위아래 밀착을 표현할 때에만 Hold 프로필의 종료 높이를 0~0.06으로 허용한다. 원형 칩의 모양은 유지한다.

한 행이 한 동작 지점이다. Progress는 시전 구간의 0~1이다. Forward는 시전 시작 때 공격자에서 접수자 방향, Side는 그 방향의 왼쪽이다. 좌표의 기준점은 시전 시작 때 접수자의 위치이며, 1단위는 링 반폭이다. Height는 링 또는 링 밖 바닥으로부터의 높이다. Start는 시전 시작 높이를 유지한다. Yaw는 수평 방향, Roll은 앞뒤 회전 각도이며 단위는 도다.

Progress 0은 이전 이벤트의 마지막 자세에서 자동으로 생성한다. 마지막 행은 Progress 1과 두 선수의 Height 0이어야 한다. 현재 피격 효과에 맞춰 Progress 0.65 지점을 포함한다. 링 경계에서는 기술에 필요한 공간을 안쪽으로 확보하고, 기술의 마지막 좌표·높이·방향을 다음 이벤트에 넘긴다. 실패·반격·회피 결과에는 성공 동작을 적용하지 않는다.

수플렉스는 공격자 뒤로, 벨리 투 벨리는 옆으로 던진다. 파워밤은 앞으로 내려찍고, 파일드라이버·브레인버스터는 공격자 가까이 수직으로 떨어뜨린다. 스피어는 두 선수가 함께 전진한다. 문설트·슈팅 스타·450 스플래시는 시작 방향·높이·회전이 다르다. 링 안팎의 포어암처럼 같은 기술의 상황 변형은 같은 경로를 사용한다.

일반 칩은 수평 원형이다. 높이는 원의 균등한 확대와 그림자로, 앞뒤 회전은 방향 표식의 위치로 표현한다. 버티컬 수플렉스는 아래의 표현 선택에서 원형 칩과 캡슐을 같은 재생 위치에서 비교할 수 있다. 초기 선택은 원형 칩이며, 원을 찌그러뜨리거나 기울이지 않고 같은 이동·높이·착지 반동을 보여준다. 캡슐은 지름 0.55, 길이 1.1로 양끝이 둥글다. Unity 기본 캡슐 메시를 균등하게 확대하며, 옆면과 둥근 끝도 해당 선수의 파란색·빨간색을 유지한다. 바깥 캡슐의 뒷면과 96% 크기의 색상 캡슐을 함께 그려 어느 자세에서도 검은 테두리가 보이게 한다. 접수자를 거꾸로 들어 유지한 뒤 두 캡슐이 뒤로 넘어가며, 마지막에는 누운 자세를 유지한다. 이 비교 기능은 경기 화면이나 다른 기술에는 적용하지 않는다. 팔·다리와 관절의 자세를 그리는 인체 애니메이션은 포함하지 않는다.

`artifacts/author_move_motions.py`는 최초 동작 데이터 작성에 사용했다. 실행 시 CSV 전체를 다시 쓰므로, CSV를 직접 수정한 이후에는 실행하지 않는다. 동작 테이블의 검증은 `MoveMotionTable.Parse`, 경기 동작은 `MatchMoveMotionTests`, 씬 선택·검색·재생은 `MovePreviewSceneBuilder.Check`에서 확인한다.

버티컬 수플렉스 미리보기는 착지 시점인 Progress 0.65 이후 0.66초 동안 작게 두 번 튕긴 뒤 가라앉는다. 접수자가 시전자보다 더 크게 반동하며, 높이·앞뒤 흔들림·균등한 원근 확대·그림자 이동을 함께 적용한다. 정수리 시점에서도 반동이 보이도록 몸통이 착지 방향으로 살짝 밀려나고 옆으로 흔들리며 링 평면에서 회전한다. 반동과 회전은 점차 줄어들어 기록된 종료 위치에서 멈춘다. 캡슐 자체를 찌그러뜨리지 않고, 바닥 아래로 내려가지 않게 접촉 높이를 유지한다. 물리엔진을 사용하지 않는 시점 기반 연출이므로 되감기·일시정지·배속에서도 같은 시점의 자세가 같다.

지원하는 다른 2인 기술도 원형 칩으로 같은 감쇠 반동을 표현한다. 기술별 동작 표의 실제 낙하 높이·착지 방향·접촉 자세에 따라 강도와 방향을 달리하며, 공중에서 내려온 시전자나 서 있다가 이동하며 쓰러진 접수자에게 착지 반동을 적용한다. 이미 누운 상대가 맞는 경우와 서서 발로 착지하는 경우는 반동을 줄인다. 탐색·타이업·체인·서브미션 유지와 암 링거처럼 상대가 제자리에 있는 부위 잡기에는 착지 반동을 넣지 않는다. 새 반동은 미리보기의 표현에만 적용하며 경기 판정과 기록된 기술 경로는 변경하지 않는다.

서브미션은 거는 동작의 절반 이후 접수자만 0.55초마다 0.18초 동안 흰색으로 밝아졌다가 돌아온다. 서브미션 시그니처·피니셔와 이후 Hold 유지 공방에도 적용하고, 실패·반격·탈출·로프 브레이크·중단·탭아웃 이후에는 점멸하지 않는다. 충돌 파동이나 카메라 흔들림 없이 지속 압박을 표시하며, 경기 화면과 미리보기에서 같은 표시를 사용한다. 시점 기반 효과이며 추가 대미지는 계산하지 않는다.

기술 정보 오른쪽의 인체 모양은 경기 화면의 `LimbDamageIndicator`를 재사용한다. 기술 데이터의 TargetRegion에 해당하는 머리·몸통·팔·다리만 붉게 강조하고 부위 이름을 함께 표시한다. 미리보기의 강조값은 공격 부위 표시용이며 누적 피해량을 뜻하지 않는다. 탐색·타이업·체인은 공격 부위를 ‘없음’으로 표시하고, 검색 결과가 비면 강조를 지운다.

평면 이동은 중간 동작마다 정지하는 SmoothStep 대신 이웃 구간의 이동 속도를 연결하는 단조 Hermite 보간을 사용한다. 같은 방향으로 달리는 동안 속도가 계속 이어지고, 제자리 유지나 방향 전환에서는 감속한다. 기록된 각 시점의 위치를 그대로 통과하며 구간 경계를 넘지 않는다. 높이·방향·자세의 기존 보간은 유지한다.

달리기 타격은 Progress 0~0.195에서 가속하고 0.65의 접촉까지 속도를 유지하며, 충돌 뒤에 감속한다. 뒤로 물러나는 기술은 0.72까지 짧게 전진한 뒤 원래 종료 위치로 돌아간다. 실제 경기의 기본 화면 길이는 일반 공격 0.8초, 시그니처·피니셔 1.1초이며, 이전 달리기에서 이어받은 길이와 진입 속도는 유지한다. 미리보기의 달리기 타격은 1× 기준 2초로 재생하고 0.5×·1.5× 선택도 지원한다. 상대가 로프에서 달려오는 것을 받아치는 상황은 시전자의 돌진으로 바꾸지 않는다. 들어 올리기와 붙잡기가 포함된 달리기 그래플은 기존 재생 방식을 유지한다.

접촉이 빠진 성공 타격은 화면에서 Progress 0.65에 두 원형 칩이 닿도록 시전자의 접근을 보완한다. 접수자의 평면 반동은 접촉 이후에 시작해 Progress 0.8에 기록된 피격 위치를 지나고 종료 지점에서 원래 경로로 돌아간다. 일반 타격과 타격형 시그니처·피니셔에 공통 적용하고, 스피어처럼 원래 경로에서 이미 접촉하는 기술과 실패·반격에는 보완을 넣지 않는다. 이 접촉 보완은 경기와 미리보기의 시각적 표현에 적용하며 판정·피해량·기록된 종료 좌표는 변경하지 않는다.

타격의 접촉 보완에서는 접수자가 맞은 직후부터 피격 위치로 밀려난다. 중간 정지 구간을 재생하지 않고 빠르게 밀려난 뒤 감속하며, 미리보기의 추가 앞뒤·좌우 흔들림은 타격 기술에 적용하지 않는다. 타격의 매트 반동은 Progress 0.8 이후 높이와 균등 확대만으로 표현하여 밀려나는 방향을 되돌리지 않는다.

Hold 동작의 시전자는 현재 좌표에서 기술별 잡기 위치까지 Progress 0~0.5에 걸쳐 점진적으로 접근한다. 중간 프레임의 짧은 이동에 접근이 몰리지 않으며, 기술별 종료 위치와 방향은 유지한다. 선택 목록의 글자는 각 행 높이 전체를 사용해 세로 중앙에 배치한다.

크로스페이스는 기술을 유지하는 Progress 0.5부터 두 선수가 같은 방향을 바라본다. 슈퍼킥 시전자의 타격 후 후퇴는 타격감을 위해 기존 동작을 유지한다.

경기 재생의 원카운트·투카운트·니어폴 킥아웃은 Progress 0.65까지 핀을 유지한 뒤, 0.78까지 핀한 선수를 짧게 밀어낸다. 접수자는 살짝 들썩이고 두 선수는 원래 종료 위치와 높이에 안정된다. 핀폴과 심판에 의한 중단에는 이 킥아웃 반동을 적용하지 않는다.

2026-10-08 전수 점검 이후 크로스페이스·보스턴 크랩·싱글 레그 크랩의 엎드림, 친록의 앉음, 지상 서브미션 시전자의 누움·앉음·무릎 자세를 반영했다. 피겨 포는 서로 반대 방향을 본다. 웨이스트록·해머록·헤드록·리스트록은 Hold 프로필의 완만한 접근을 사용하며, 비타격 잡기와 체인 전환은 타격 섬광을 만들지 않는다. 미사일 드롭킥과 다이빙 더블 액스 핸들은 0.65에 접촉한 뒤 0.8까지 접수자가 밀려난다. 초크슬램은 Grapple/Slam으로 분류하고 들어 올리기 동안에는 효과를 내지 않으며 0.65의 내려꽂기에 효과를 낸다.

카멜 클러치와 트라이앵글 초크는 기술에 맞는 위아래 높이와 작은 측면 간격으로 두 칩의 테두리가 읽히게 한다. 방향 표시 점은 칩의 윗면 가까이에 얇게 배치한다. 카메라에서 점으로 향하는 시선이 다른 원형 칩에 먼저 닿으면 해당 점을 숨기며, 겹침이 풀리면 다시 표시한다. 이 처리는 실제 경기와 미리보기에서 공통으로 적용한다.

타격 효과는 설치된 Wallcoeur 무료 팩의 Classic 01 기반 `Match Impact` 프리팹을 사용한다. 색과 잔광을 줄이고 실제 이벤트 충격량에 따라 크기와 선명도를 높인다. 기술 미리보기의 기본 충격량도 경기 엔진의 기술 유형별 기준을 공유한다. 접촉·착지 시점에만 발생하며 서브미션의 주기적 점멸과 비타격 잡기의 제어 점멸은 기존 방식을 유지한다.
