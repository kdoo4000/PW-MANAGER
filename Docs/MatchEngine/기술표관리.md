# 기술표 관리

## 원본과 반영

원본: `Assets/Game/Data/Resources/PWManagerRuntime/MatchMoves.csv`

Excel에서 UTF-8 CSV로 편집하고 저장한다. Unity 메뉴 `PW Manager > Import Move Table`로 반영한다.
임포터는 전체 표를 검사한 뒤 기존 기술 자산을 ID로 찾아 갱신하고, 정적/런타임 카탈로그를 함께 갱신한다.
기존 기술 자산의 GUID는 유지한다. 생성 자산을 직접 편집하면 다음 임포트에서 표의 값으로 덮어쓴다.
`Generate Confirmed Static Content`도 동일한 기술표를 사용한다.

현재 표는 178행이며 활성 기술은 150개다. 이 중 일반 기술 풀은 129개다.
첫 확장 기술 28개에 이어 후면/엎드림/앉음/무릎 자세의 기술 6개를 활성화했다.
비활성 28개는 미지원 상황 예시 25개와 중복 호환용 3개다.

## 열 정의

- Id / Key: 영구 기술 ID / 기존 로그와 기술 동작을 찾는 별칭. 중복 금지. 기존 항목은 삭제하지 않고 Enabled를 끈다.
- KoreanName / EnglishName: 화면과 관리용 이름. 쉼표, 따옴표, 줄바꿈은 CSV 인용 규칙을 따른다.
- Action / Situation / Kind / TargetRegion: 행동 종류, 사용 상황, 실행 방식, 손상 부위.
- AllowedStyleIds: `style_004;style_005;style_007`처럼 세미콜론으로 구분. 빈 값은 공통 기술.
- Enabled / CanUseGenerally: 기술 활성 여부 / 스타일별 일반 기술 풀 포함 여부.
- CanBeSignature / CanBeFinisher: 개인 슬롯 지정 자격. 실제 선수 지정은 선수 데이터에 따로 남는다.
- BrawlingWeight / PowerWeight / TechnicalWeight / HighFlyingWeight: 각 비중은 0~1, 합계는 1.
- ExecutionDifficulty / SellingDifficulty: 실행 난이도 1~20 / 받아내기 난이도 7, 10, 13, 16 중 하나.
- RequiredStat / RequiredStatValue: None, Brawling, Power, Technical, HighFlying / 최소 능력치. None이면 0, 나머지는 1~20.
- MotionProfile / EndPosture / TravelDistance: 공유 동작 유형 / 다운 시 종료 자세 / 상대 이동 거리. 거리는 링 반폭 단위로 0~0.8이다.
  이미 다운된 상대의 일반 타격은 자세를 유지한다. 잡기/서브미션의 자세 전환은 기술 실행 안에 기록한다.

## 스타일

style_001 브롤러, style_002 파워하우스, style_003 테크니션, style_004 하이플라이어,
style_005 루차 리브레, style_006 자이언트, style_007 올라운더.

스타일은 일반 기술의 허용 범위다. 능력치는 그 안의 선호도와 수행 품질에 반영된다.
올라운더도 특수 기술을 자동으로 모두 얻지 않는다. 표의 허용 스타일에 명시되어 있어야 한다.
스타일 없는 독립 테스트용 참가자는 기존 공용 선택과 호환된다. 실제 선수 경기/미리보기에는 스타일 ID를 전달한다.

## 현재 지원 범위

탐색, 타이업, 체인, 서 있는 상대의 기본/강한 타격과 잡기, 서 있는/누운 상대의 부위 공격,
그라운드 공격/서브미션, 스탠딩 홀드, 서 있는/누운 상대의 다이빙과 러닝 공격,
코너 공격, 링사이드 공격, 코너 위 잡기, 더블팀을 지원한다.

러닝/코너/링사이드/코너 위 잡기/더블팀은 공방의 준비 과정을 통해 일반 기술로 사용한다.
이 상황의 개인 시그니처/피니셔 준비는 아직 연결하지 않았으므로 해당 행의 지정 자격은 꺼두었다.
기존 24개 개인 기술은 기존 선수 지정과 호환되는 상황/능력치를 유지한다.

후면 기술은 실제 상대 방향과 공격자 위치를 검사한다. 엎드림/앉음/무릎 자세 전용 기술도 현재 자세를 검사한다.
러닝 세부 자세, 링 밖 다이빙, 스프링보드, 에이프런 등은 분류와 예시 행을 마련했지만 비활성이다.
현재 엔진에 없는 자세를 문구로만 구현하지 않는다. 상태와 준비 흐름을 지원한 후 활성화한다.

## 중복과 호환

크로스페이스, 다이빙 엘보드롭, 슈퍼킥은 기존 개인 기술 ID를 일반 풀에서도 재사용한다.
표 연결 중 생성된 중복 ID 세 개는 compat- 키의 비활성 행으로 보관하며 경기와 신규 지정 목록에는 나오지 않는다.
기존 일반 기술 키는 모두 조회 가능하다. 기존 선수의 현재 지정은 변경 화면에서 유지하며 새 선택에는 자격/스타일/최소 능력치를 검사한다.

## 추가 순서

1. 고유한 move_XXX ID와 Key를 지정한다.
2. Action/Situation/Kind 조합을 확인한다. 미지원 상황은 Enabled=False로 보관한다.
3. 허용 스타일, 일반 사용 여부, 시그니처/피니셔 자격을 각각 정한다.
4. 손상 부위, 능력치 비중, 난이도와 최소 능력치를 정한다.
5. 임포트하고 실제 경기와 지정 목록을 확인한다.

기술별 동작 설정으로 엔진이 준비/접촉/실행/종료 위치와 방향, 자세, 잡기를 기록한다.
TopView Arena Test는 이 기록을 재생한다. 이전 버전의 경기에는 기존 위치 재생을 유지한다.
무브셋의 나머지 세부 상황, 캐리/에이프런/특수 경기 동작과 셀링 확장은 개선계획.md의 후속 단계다.
