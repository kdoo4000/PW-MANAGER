## 수치와 호환성

최초 변환만 `선호도 = (기존 반응 + 100) × 0.5`, `관심도 = abs(기존 반응)`을 사용한다. 이후 두 축은 서로 독립이다. 선호도 50/관심도 90도 그대로 저장·복사·표시된다. 각 축의 유효 범위는 0~100이며 NaN·무한대와 범위 밖 저장은 거부한다.

| 기존 반응 | 새 선호도 | 새 관심도 |
| ---: | ---: | ---: |
| -100 | 0 | 100 |
| -40 | 30 | 40 |
| 0 | 50 | 0 |
| 40 | 70 | 40 |
| 100 | 100 | 100 |

이 변환은 과거 단일 값에서 환호·야유 방향과 강도를 대칭적으로 보존하기 위한 정책이다. 과거 0에서 ‘논쟁적이지만 높은 관심’을 역산할 근거는 없으므로 새 관심을 부여하지 않는다. 기존 후보 생성기는 팬 반응을 설정하지 않아 0으로 시작하므로 초기 화면은 각 팬층 선호 50/관심 0이다. 단체 규모·성장 속도를 조정할 실행 데이터와 경제 연결은 아직 없으므로 관련 보상·가격·수요 계수는 변경하지 않았다.

UsesTwoAxes가 재변환을 막으며, 구형 필드와 저장 버전은 유지했다. 파일 로드는 기존 유효성 검사 통과 후 메모리에서 변환하고 원본 파일을 자동 덮어쓰지 않는다. 다음 저장 때 독립 축을 보존한다. 기존 저장과 백업의 로드, 새 저장의 재로드를 확인했다. 구버전 프로그램으로 다시 저장하면 새 필드는 소실될 수 있으므로 양방향 편집 호환을 보장하지 않는다.
